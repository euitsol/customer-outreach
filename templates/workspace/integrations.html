How to connect
  1. In Meta for Developers create a Business app and add the WhatsApp product.
  2. Add your number, then copy the Phone number ID and a permanent system-user access token (with whatsapp_business_messaging).
  3. Put them in .env as WHATSAPP_PHONE_NUMBER_ID and WHATSAPP_TOKEN, plus WHATSAPP_APP_SECRET (App settings > Basic) and a WHATSAPP_VERIFY_TOKEN you make up.
  4. Redeploy, then in WhatsApp > Configuration set the webhook URL above with that verify token and subscribe to messages.
  5. Send the test below. New conversations must start with an approved template; once someone writes to you, free text is allowed for 24 hours.
