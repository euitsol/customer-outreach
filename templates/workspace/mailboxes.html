The password is stored in the CRM database and is never shown again. A new mailbox sends nothing until you choose it in a campaign's Settings.

How several mailboxes work

  • A campaign sends from the mailboxes ticked in its Settings. With none ticked it uses the first active mailbox only, so adding a mailbox never changes an existing campaign.
  • With several ticked, each new email goes out from the mailbox that has sent the fewest emails today. Follow-ups to a person stay on the mailbox that wrote to them first.
  • A mailbox's daily limit is added to the global and per-campaign limits. When every ticked mailbox has reached its limit, the campaign waits until tomorrow.
  • Replies and bounces are read from every active mailbox that has IMAP set up.
