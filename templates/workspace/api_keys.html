{{ icon('link') }} Connect Claude (MCP)

The MCP server lets Claude search and update this CRM: people, companies, deals, notes, tasks, campaigns and the inbox. Every change Claude makes is recorded in the audit log under the key's name, and sending email / WhatsApp needs the send scope.

Claude Code (remote, over HTTP)

claude mcp add --transport http outreach-crm {{ base }}/mcp --header "Authorization: Bearer YOUR_KEY"

Requires the mcp service from docker-compose and a proxy from {{ base }}/mcp to port {{ mcp_port }} (see README). Locally: http://localhost:{{ mcp_port }}/mcp.

Claude Desktop / Claude Code on the same machine (stdio)
