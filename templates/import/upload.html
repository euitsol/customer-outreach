What the file can contain

  • email is the only required column.
  • Contact details: first name, last name, company, phone, priority, tags, notes.
  • Personalised emails: a subject, body and send date per stage (stage1_body, stage2_body, stage2_date…). Anything left blank uses the campaign template.
  • Any other column becomes a merge field, e.g. a website column is usable as {{ '{{website}}' }}.
  • Handles sheets with title rows above the header, and older column names like "Email 1", "Follow-up 1", "Subject line".
