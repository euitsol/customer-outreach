# API key ও Claude

Claude ও অন্য টুলকে নিরাপদে আপনার সিআরএমে কাজ করতে দিন।

## এটি কী কাজে লাগে

Claude (Claude Desktop, Claude Code বা claude.ai) সিআরএমের সঙ্গে সংযুক্ত করা যায়। তখন Claude রেকর্ড খুঁজতে, পড়তে ও হালনাগাদ করতে, নোট লিখতে, টাস্ক ও ডিল তৈরি করতে, মানুষকে ক্যাম্পেইনে enroll করতে এবং আপনি অনুমতি দিলেই শুধু মেসেজ পাঠাতে পারে। যেমন জিজ্ঞেস করতে পারেন:

* "আজকের সিআরএম ব্রিফিং দাও।"
* "Ireland ক্যাম্পেইনে এই সপ্তাহে কারা রিপ্লাই দিয়েছে, তারা কী চায়?"
* "Sprout & Co-র জন্য €18k-র একটি ডিল তৈরি করো, stage Qualified, আর শুক্রবার প্রস্তাব পাঠানোর একটি টাস্ক রাখো।"

## key তৈরি

1. *Workspace > Users & API keys > API keys & Claude*-এ গিয়ে **Create a key** ক্লিক করুন।
2. একটি নাম দিন এবং অনুমতি বেছে নিন:

| অনুমতি | key যা করতে পারে |
|---|---|
| `read` | person, company, deal, টাস্ক, ক্যাম্পেইন ও কথোপকথন খোঁজা ও দেখা |
| `write` | person, company, deal, টাস্ক তৈরি ও হালনাগাদ; নোট লেখা; মানুষ merge করা; ক্যাম্পেইনে enroll করা |
| `send` | মানুষকে ইমেইল বা WhatsApp পাঠানো, ক্যাম্পেইন শুরু, pause বা archive করা: যা আসল মানুষের কাছে পৌঁছায় |

3. চাইলে **Expires after (days)** দিন।
4. **key এখনই কপি করুন। এটি শুধু একবারই দেখানো হয়।**

## জেনে রাখুন

* `read` + `write` দিয়ে শুরু করুন। যে key দিয়ে মেসেজ পাঠাতে চান শুধু তাতেই `send` দিন।
* key যেকোনো সময় বাতিল (revoke) করা যায়; *Last used* ব্যবহারের সময় দেখায়।
* Claude যা বদলায় তা [অডিট লগে](/help/audit) "Claude" নামে দেখা যায়।
* প্রতিটি Claude অ্যাপ সংযোগের ধাপ এই পেজে এবং [Integrations](/help/integrations)-এ আছে।
