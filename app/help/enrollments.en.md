# Enrollments

Who is in which campaign, and how far they have got.

## What it is for

An **enrollment** is one person's membership of one campaign, with their progress. A person can be in several campaigns, but only once in each.

> This page used to be called "Contacts". The people themselves are under [People](/help/people). Old links still work.

## Statuses

| Status | Meaning |
|---|---|
| **Ready** | Enrolled, nothing sent yet |
| **In sequence** | Part-way through the stages |
| **Finished** | Every stage has been sent |
| **Replied** | They answered, so automatic emails stopped |
| **Unsubscribed** | They opted out |
| **Bounced** | The address does not exist |
| **Needs verification** | Flagged for a manual check before sending |
| **Paused** | Sending is switched off for this person |

## How to use it

1. Filter by campaign, status, stage reached, engagement, tag, priority or date added; search by name or email.
2. Click a person to open their **enrollment page**. It explains why nothing is being sent, if that is the case.
3. There you can override any stage's subject, text and send date, send a stage now, skip it, re-open it, or restart the sequence.
4. Tick several rows for bulk actions: queue now, retry, move to another campaign, add or remove tags, pause or resume, reset, mark unsubscribed, add to *Do not contact*, reschedule, export or delete.

## Good to know

* Existing stages that were already sent are never changed by an import or an edit.
* To remove someone from sending without deleting them, pause the enrollment.
